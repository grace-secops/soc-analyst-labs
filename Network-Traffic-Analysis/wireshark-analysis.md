Wireshark Network Traffic Analysis

 Overview

I worked on this lab to understand how network traffic can be captured and investigated using Wireshark. I used Kali Linux to generate ICMP traffic with the `ping` command and then captured and analysed the packets in Wireshark.

This exercise helped me understand how network communication looks at the packet level and how filters can be used to focus on specific types of traffic during an investigation.

Objective

The objective was to capture network traffic using Wireshark and identify and analyse the ICMP packets generated during network communication.

 Tools Used

* Wireshark
* Kali Linux

 What I Did

 1. Generated Network Traffic

I used the `ping` command to generate ICMP traffic.

```bash
ping google.com
```

The ping generated ICMP echo request and echo reply packets that I could capture and analyse.

 2. Captured the Traffic

I launched Wireshark and captured packets from the active network interface, `eth0`.

This allowed me to see the network communication happening in real time.

 3. Filtered ICMP Packets

I applied the `icmp` display filter in Wireshark to isolate the ICMP packets generated by the ping command.

![ICMP Packet Analysis](wireshark-icmp-filter-analysis.jpeg)

Filtering the traffic made it easier to focus on the packets relevant to the investigation instead of going through all captured network traffic.

4. Inspected Packet Details

I selected a captured packet and examined its frame information and protocol structure, including Ethernet, IPv4 and ICMP.

![Packet Frame Details](wireshark-frame-details.jpeg)

 5. Examined the Packet Hex Data

I also looked at the raw hexadecimal representation of the packet to understand how the captured data is represented at a lower level.

![Packet Hex Data](wireshark-packet-hex.jpeg)

 What I Observed

The captured traffic contained ICMP echo request and echo reply packets between the local host and the remote server. I was able to follow the communication from the generated ping through the captured packets and inspect the different protocol layers.

 What I Learned

This lab helped me gain practical experience with:

* Capturing network traffic with Wireshark
* Using display filters to isolate specific traffic
* Identifying ICMP packets
* Examining Ethernet, IPv4 and ICMP information
* Understanding packet structure
* Looking at raw packet data in hexadecimal format

Challenge

One part I found challenging was understanding all the information displayed in a captured packet. There were many fields and layers to look through, and it was initially difficult to know what each section meant. Working through the packet details helped me become more comfortable reading captured traffic and understanding how the different protocol layers fit together.

 Conclusion

This exercise gave me a better understanding of how network traffic can be captured and investigated at the packet level. It also showed me how useful Wireshark can be when analysing network communication and looking for unusual or suspicious activity.
